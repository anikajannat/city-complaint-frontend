# CityCare Frontend — B7A7

## Stack
Next.js App Router + TypeScript + Tailwind CSS + Radix UI dependency + TanStack Query + Zustand + React Hook Form + Zod + Recharts + Sonner.

## Included
- Modern responsive landing/public pages
- 3 roles: CITIZEN / STAFF / ADMIN
- One-click demo login for all three roles
- Citizen complaint creation, search/filter URL state, details, feedback, payment history
- Staff task workflow
- Admin analytics, user management, categories, complaint assignment
- SSLCommerz redirect pages
- Global loading, error and 404 pages

## Local
```bash
cp .env.example .env.local
npm install
npm run dev
```
Open http://localhost:3000
